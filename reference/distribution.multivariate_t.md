# distribution.multivariate_t

Constructor function for an object of class
`distribution.multivariate.t.class`

## Usage

``` r
distribution.multivariate_t(means, scale_matrix, df)
```

## Arguments

- means:

  the means of the multivariate t-distribution

- scale_matrix:

  the scale matrix of the multivariate t-distribution
  (cov=scale\*dt/(df-2))

- df:

  the degrees of freedom for the t
