# distribution.truncated.exponential

Constructor function for a random variable distributed under a truncated
exponential distribution.

## Usage

``` r
distribution.truncated.exponential(rate = 1, t0 = 0, t1 = Inf)
```

## Arguments

- rate:

  vector of rates

- t0, t1:

  Lower and upper limits for truncation

## Value

An object of class
