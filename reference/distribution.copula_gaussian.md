# distribution.copula_gaussian

Constructor function for a Gaussian copula

## Usage

``` r
distribution.copula_gaussian(distributions, rho)
```

## Arguments

- distributions:

  a list of univarite distributions

- rho:

  single correlation in the copula

An object of class
