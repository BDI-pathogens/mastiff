# distribution.beta_binomial

Constructor function for an object of class
\[[distribution.discrete.beta_binomial.class](https://bdi-pathogens.github.io/mastiff/reference/distribution.discrete.beta_binomial.class.md)\]

## Usage

``` r
distribution.beta_binomial(size, alpha, beta, mu, var)
```

## Arguments

- size:

  number of trials (zero or more).

- alpha:

  the first shape parameter

- beta:

  the second shape parameter

- mu:

  the mean of the distribution (ALTERNATIVE PARAMETERISATION)

- var:

  the variance of the distribution (ALTERNATIVE PARAMETERISATION)

An object of class
