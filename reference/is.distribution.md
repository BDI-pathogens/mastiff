# is.distribution

Checks whether an object `x` is a R6 distribution class implemented by
[mastiff](https://bdi-pathogens.github.io/mastiff/reference/Mastiff-Distributions.md),
i.e. inherits either
[distribution.discrete.class](https://bdi-pathogens.github.io/mastiff/reference/distribution.discrete.class.md)
or
[distribution.continuous.class](https://bdi-pathogens.github.io/mastiff/reference/distribution.continuous.class.md)

## Usage

``` r
is.distribution(x)
```

## Arguments

- x:

  An R object.
