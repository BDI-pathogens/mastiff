# distribution.copula_t

Constructor function for a t-copula

## Usage

``` r
distribution.copula_t(distributions, rho, df)
```

## Arguments

- distributions:

  a list of univarite distributions

- rho:

  single correlation in scale matrix of the t

- df:

  degrees of freedom in the t

## Value

An object of class
